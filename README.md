# usage 
**web version**
1. open the website: <a href="https://scienceequationfixer.netlify.app" target="_blank">scienceequationfixer.netlify.app</a>
2. enter your elements
3. press on send
4. under the send key is your result

**app version**
1. download the .exe at releases
2. open the .exe by double tapping it
3. to use it follow the steps 2, 3 and 4 of the webversion

## developer-guide
to change the code or run experiments you would have to run it without the .exe

1. download the files and put everything except README.md an the map DEMO in an map
2. make sure to download node.js at <a href="https://nodejs.org/en" target="_blank">node.js</a>
3. use
```bash
cd directory
```
to get to the map where your project is located
4. run
```bash
npm install
```
to set up your program
5. to run the program use
```bash
npm run dev
```
6. when your project is finished use
```bash
npm run build 
```
to create the .exe file

7. find your .exe in the dist/win-unpacked directory
